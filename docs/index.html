Как запустить

  1. Откройте скачанный HB_AI_Xbox_DNS.exe.
  2. Если Windows напишет «Windows защитила ваш компьютер», нажмите Подробнее → Выполнить в любом случае, на вопрос о правах администратора — Да. Без этих прав Windows не даст поменять DNS.
  3. Выберите сервис и нажмите большую кнопку. Программа сама проверит, что открывается.
  1. Распакуйте архив и перетащите «HB AI Smart DNS» в «Программы».
  2. При первом запуске нажмите на программу правой кнопкой → Открыть → Открыть. Это нужно один раз.
  3. Нажмите большую кнопку и введите пароль администратора: DNS меняется стандартной командой macOS.
